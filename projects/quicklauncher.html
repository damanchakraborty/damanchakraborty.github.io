QuickLauncher

A fast, keyboard-driven application launcher for Hyprland, built with Quickshell.

QMLQuickshellHyprlandLinux

The idea

QuickLauncher is designed to make launching applications and commands feel instant while fitting naturally into a keyboard-driven Hyprland desktop.

Features

  • Keyboard-first application search
  • Fuzzy matching
  • Command search
  • Calculator mode
  • Animated interface
  • Modular QML services

Next

The launcher is being expanded into a broader desktop utility while keeping the interface fast and unobtrusive.
