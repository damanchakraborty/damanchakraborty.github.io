Portable IDE

A Vim-inspired editor with modern features and a plugin architecture, designed to be portable.

Cross-platformPluginsEditorIn progress

Goal

The idea is a small, fast IDE that keeps the keyboard-driven philosophy of Vim while making richer functionality easy to add through plugins.

Planned direction

  • Portable Windows and Linux builds
  • Plugin API for extending the editor
  • Project/file navigation
  • Command palette and configurable keybindings
  • Language tooling without turning the core into a monolith
