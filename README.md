# Daman — Personal Portfolio

Static GitHub Pages portfolio.

## Deploy

1. Create a GitHub repository.
2. Copy all files from this folder into the repository root.
3. Push to GitHub.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main`, and `/ (root)`.
6. Save.
